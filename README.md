# Butler-Smith Developments — WordPress Theme

Bespoke Elementor-powered WordPress theme for **Butler-Smith Developments — Prestige Property Development**.

## Features
- **Modern Elementor Architecture**: 12 custom flexbox container widgets extending `BSD_Widget_Base`.
- **Exact Typography & Tokens**: Uses Google Font `Roboto` with scoped `--bsd-*` tokens matching the live design.
- **Custom Post Type**: Built-in `development` CPT with specifications meta box.
- **Client Inquiries & CRM**: Database logging (`wp_bsd_submissions`), AJAX submission handling, and admin leads viewer.
- **1-Click Demo Import**: Programmatic page seeder under **Appearance > Demo Import**.
- **Automated OTA Updates**: Powered by Plugin Update Checker (PUC) from GitHub releases.

## Installation
1. Download `butler-smith.zip` from [Releases](https://github.com/hellomahfuzpro/butler-smith-theme/releases).
2. Go to **WordPress Admin > Appearance > Themes > Add New > Upload Theme**.
3. Activate the theme.
4. Run **Appearance > Demo Import** to generate all pages and navigation menus.
